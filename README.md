# JavaScript Practice

A structured collection of JavaScript exercises and examples created to strengthen my understanding of core JavaScript concepts and modern language features.

## Topics Covered

- **Fundamentals:** Variables, data types, operators and control flow
- **Functions:** Function declarations, expressions, arrow functions and scope
- **Array Methods:** `map()`, `filter()`, `reduce()`, `find()` and other array operations
- **Asynchronous JavaScript:** Promises, `async/await` and asynchronous execution
- **Modern JavaScript:** ES6+ features and language improvements

## Repository Structure

```text
javascript-practice/
├── fundamentals/
├── functions/
├── array-methods/
├── asynchronous-javascript/
├── modern-javascript/
├── index.html
└── README.md
```

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/sasamir10/javascript-practice.git
   ```

2. Open the repository in your code editor.
3. Run the relevant JavaScript example using Node.js or open `index.html` in a browser, depending on the exercise.

## Purpose

This repository documents my ongoing JavaScript learning journey through practical exercises, problem-solving and experimentation with language fundamentals.

The focus is on building a strong foundation for developing applications with React and Next.js.
